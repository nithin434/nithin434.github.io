Research at the AIR Centre, VIT-AP

The Artificial Intelligence and Robotics (AIR) Research Centre is a Centre of Excellence at VIT-AP University, Amaravati. I worked there as a student researcher from Jun 2024 to Nov 2025:

  • NeuroSecAPI. A neuro-symbolic system in which LLMs generate attack payloads (SQLi, XSS, BOLA) from live API metadata. It found 34% more vulnerabilities than standard SAST/DAST tools and cut manual security testing by 70% with OWASP-aligned risk scoring. The pipeline runs input validation → fuzzing → auth checks → exposure analysis across multi-service APIs.
  • Voice automation. An automated outbound calling system built on ViciDial and Asterisk, plus applied research on outreach optimisation.
